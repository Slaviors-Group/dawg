# Contributing to DAWG

DAWG's source code is publicly available for transparency, learning, and local
use. Public availability does **not** mean that external code contributions are
currently open.

## Pull requests

Please do not open pull requests, submit patches, or request repository write
access at this time. The maintainers are not accepting external code,
documentation, translation, design, or dependency contributions.

Pull requests may be closed without review while this policy is in effect.

## Feedback and bug reports

Feedback is welcome. Use [GitHub Issues](https://github.com/Slaviors-Group/dawg/issues)
to report a reproducible bug or request a feature, and use repository
Discussions or the project's published contact channel for questions that do
not belong in an issue.

When reporting a bug, include:

- concise reproduction steps without secrets or production credentials;
- expected and actual behavior;
- operating system, DAWG version, and browser version;
- relevant `dawg doctor` output and non-sensitive logs.

Do not attach a captured `.dawg` artifact until you have reviewed it for
sensitive information. DAWG sanitization reduces exposure but is not a
confidentiality guarantee.
